# Core Concepts

解释 LayerBase 的核心概念。

## 概念列表

- **Layer**: 逻辑分层容器。
- **Service**: 依赖注入服务。
- **Event**: 基于发布订阅的通信。
- **Call**: 请求响应式通信。
- **Shared Field**: 共享数据存储。
- **Send/Post**: 事件发送方式。
- **Pump**: 框架驱动心跳。
- **Local/Global**: 通信作用域。
- **Source Generator**: 代码自动生成。
- **LBTask**: 异步任务。
- **Topology Audit**: 架构审计。
